# 茶會小遊戲系統

這個系統包含兩款互動遊戲：

- **猜歌曲**：播放音樂或提示，參與者猜出歌曲名稱。
- **挖掘猜角色**：挖開圖片，猜出角色身份。

## 功能介紹

- 伺服器模式運行，可在同一網路下使用電腦投影與手機查看答案。
- 內建題目編輯器，可新增、修改題目與上傳檔案。
- 支援單機模式，適合網路隔離環境。

## 快速開始

1. 安裝 Node.js（LTS 版本）。
2. 在專案資料夾開啟命令列。
3. 執行 `npm install` 安裝套件。
4. 執行 `node backend.js` 啟動伺服器。
5. 在瀏覽器開啟顯示頁面：
   - 主遊戲頁：`http://[您的IP]`
   - 答案頁：`http://[您的IP]/GameAnswer`
6. 若要編輯題目：
   - 使用 `http://[您的IP]/editor`
   - 點選「新增題目」或上傳檔案
   - 完成後記得點「保存所有變更」

## 注意事項
- 若手機無法連線，請確認主機與手機是否在同一個 Wi-Fi，並檢查防火牆設定。
- 若學校網路不允許裝置互連，可使用單機延伸螢幕方案，將主頁與答案頁分別顯示在不同螢幕上。
